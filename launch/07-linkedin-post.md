# LinkedIn post

5.29 million output tokens. 224 coding sessions. A $0 local API line item.

Across the November 3–8 snapshot, the retained OpenCode ledger recorded 5,290,865 output tokens — 5,090,841 coding plus 200,024 compaction — across 224 coding sessions on one workstation.

The case study ran an 83.6 GB model with 16 GB of GPU memory, using host RAM and NVMe offload. This describes one measured workstation configuration, not a general hardware guarantee.

The cloud figures price the same recorded token mix at listed rates: Codex GPT-6 Luna $8.43, Cursor Composer 2.5 $98.16, Codex GPT-6.1 Sol $131.32, Cursor GPT-5.3 Codex $175.34, Cursor Grok 4.7 $259.48. They are counterfactuals, not invoices or quality comparisons. The $0 figure is the local API charge in this ledger; it does not mean the workstation has no operating cost.

Cache reads covered 94.79% of recorded input. v1.2.0 is the economics continuation; the v1.0.x paper releases remain. Swipe the carousel, then read the whitepaper (Section 5.7) and the full token report, linked below.
